# Memory Bridge for Mem0

Browser extension for Microsoft Edge and Chrome that saves what matters from your ChatGPT, Gemini and Claude conversations to your own [Mem0](https://mem0.ai) account.

Extensão para Microsoft Edge e Chrome que salva o que importa das suas conversas do ChatGPT, do Gemini e do Claude na sua própria conta [Mem0](https://mem0.ai).
